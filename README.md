# Smoke 💨

Высокопроизводительный, легковесный DPI-bypass прокси для Windows, написанный на **Rust** (Tokio).

Разработан по принципу **Zero-Config**: обходит блокировки и замедления ТСПУ (YouTube, Discord и др.) без необходимости устанавливать сторонние драйверы (WinDivert), без прав администратора и без сложных настроек.

## ⚡ Особенности и преимущества

- **Работа в User-Space (Без драйверов)**: Не требует установки WinDivert или прав администратора — работает как локальный интеллектуальный прокси.
- **Мультипротокольность на одном порту**:
  - На порту `127.0.0.1:1080` одновременно работают и **HTTP CONNECT** (для системного прокси Windows и браузеров), и **SOCKS5** (для Telegram, curl, Discord и др.). Определение протокола происходит на лету по первому байту без лишних накладных расходов.
- **Интеллектуальные стратегии десинхронизации**:
  - `SniMiddle`: Zero-copy разрез TLS ClientHello ровно посередине имени домена в расширении SNI.
  - `TlsRecordAndSni`: Двойной разрез — после 2-го байта заголовка записи TLS (Record Header) + по центру SNI.
  - `FakeTtl`: Уникальная user-space техника отправки фейкового ClientHello/пакета с малым `IP_TTL` (пакет сбивает с толку локальный узел ТСПУ на первых 2-4 хопах, но умирает до сервера назначения, после чего отправляется реальный запрос).
  - **HTTP Desync**: Поддержка разрезания незашифрованных HTTP-запросов внутри заголовка `Host:`.
  - **Anti-Coalescing Micro-Sleep**: Паузы 2 мс между сегментами предотвращают объединение пакетов драйвером сетевой карты (TSO/LSO).
- **Многоуровневый DoH (DNS-over-HTTPS)**:
  - Автоматический каскадный резолвер: **Google DoH** -> **Cloudflare DoH** -> **Quad9 DoH** -> **Системный DNS**.
  - Защищает от DNS-спуфинга и подмены IP-адресов.
- **Нативная интеграция с Windows (Win32 API)**:
  - Прямое управление реестром через Win32 API (`winreg`) без порождения дочерних процессов `reg.exe`.
  - Сохранение исходных настроек пользователя и их **гарантированное восстановление** при выходе (RAII) или аварийной панике (`std::panic::set_hook`).
  - Уведомление подсистемы WinINet (`InternetSetOptionW`), благодаря чему браузеры (Chrome, Edge, Яндекс) подхватывают прокси мгновенно без перезапуска.
- **Автоматический бенчмарк сети**:
  - При старте в режиме `auto` утилита параллельно тестирует стратегии на тестовых ресурсах (`youtube.com`, `googlevideo.com`, `discord.com`) и выбирает самую быструю рабочую.

## 🚀 Быстрый старт

### Запуск по умолчанию:
```powershell
cargo run --release -p smoke-cli
```
или запустите скомпилированный бинарник:
```powershell
.\target\release\smoke-cli.exe
```

После запуска откройте браузер и проверьте работу YouTube. Для завершения работы нажмите **Ctrl + C** (Smoke корректно вернет системные настройки сети в исходное состояние).

---

## 🛠 Параметры командной строки

```text
Usage: smoke-cli.exe [OPTIONS]

Options:
  -b, --bind <BIND>          Адрес и порт для запуска прокси [default: 127.0.0.1:1080]
  -s, --strategy <STRATEGY>  Стратегия десинхронизации [default: auto] 
                             [possible values: auto, tls-record, sni-middle, fake-ttl, none]
      --fake-ttl <FAKE_TTL>  TTL для стратегии fake-ttl [default: 3]
      --no-sysproxy          Не включать системный прокси Windows (для ручной настройки)
  -v, --verbose              Подробный вывод логов (DEBUG)
  -h, --help                 Показать справку
  -V, --version              Показать версию
```

### Примеры использования:

1. **Принудительный мощный режим двойного сплита**:
   ```powershell
   smoke-cli.exe --strategy tls-record
   ```

2. **Режим с обманом ТСПУ через малый TTL**:
   ```powershell
   smoke-cli.exe --strategy fake-ttl --fake-ttl 3
   ```

3. **Запуск без изменения настроек Windows (только локальный SOCKS5)**:
   ```powershell
   smoke-cli.exe --no-sysproxy --bind 127.0.0.1:1080
   ```
   *(Удобно для настройки только конкретного приложения, например Telegram: SOCKS5 `127.0.0.1:1080`)*

## 📦 Сборка релизной версии

Для сборки максимально оптимизированного бинарного файла:

```powershell
cargo build --release
```

Файл будет доступен по пути `target/release/smoke-cli.exe` (размер ~3.6 МБ, статически слинкован, без внешних DLL-зависимостей кроме стандартных системных библиотек Windows).
